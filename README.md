* Real-time AI conversations
* OpenAI API integration
* Responsive chat interface

* HTML
* CSS

* Git & GitHub
* Render

## 🚀 Run Locally

```bash
git clone https://github.com/ar-eej/First-website-Chatbot.git
cd First-website-Chatbot
npm install
```

Create a `.env` file:

```env
OPENAI_API_KEY=your_api_key_here
```

Start the server:

```bash
node index.js
```
